# 内容更新说明

## 一、日常更新：用后台（推荐）

访问 `你的网址/admin`，输入管理员密码登录。左侧菜单：

| 菜单 | 管理什么 | 前台位置 |
| --- | --- | --- |
| 概览 | 数据统计、「待完善的项目」提醒、备份与迁移 | — |
| 项目 | 项目展厅里的所有作品 | 首页精选 / 项目展厅 / 项目详情 |
| 分类 | 项目分类（同时是首页「核心能力方向」） | 筛选按钮、首页能力卡片 |
| 经历与教育 | 工作经历、教育经历 | 首页时间线、经历页、简历页 |
| 技能 | 技能分组与条目 | 经历与技能页 |
| 成长日志 | 持续更新记录 | 日志页、首页「最近更新」 |
| 个人信息 | 姓名、定位、简介、联系方式、关键数据、证书 | 首页、关于我、简历 |
| 站点设置 | 标题、描述、主题色、首页板块开关 | 全站 |
| 媒体库 | 上传 / 管理图片 | 各处图片选择 |

### 每一条记录都支持

| 操作 | 说明 |
| --- | --- |
| **新增** | 列表上方「+ 新增」 |
| **编辑** | 右侧抽屉里编辑，保存后刷新前台即生效 |
| **显示 / 隐藏** | 开关。隐藏的内容不会出现在前台，**数据保留**；列表中显示「已隐藏」 |
| **精选**（仅项目） | 是否在首页「精选项目」展示（数量上限在站点设置里） |
| **上移 / 下移** | 调整排序。搜索时排序按钮会暂时隐藏 |
| **复制** | 复制为一条**隐藏**的新记录，适合基于旧项目改写新项目 |
| **删除** | 不可恢复，删除前会二次确认。分类下还有项目时无法删除 |

### 新增一个项目（示例）

1. 项目 → 新增项目。
2. 填「项目名称」「所属分类」「当前状态」「真实性类型」「一句话简介」。
3. 「封面与媒体」：上传封面 / 截图 / 小程序二维码。**换成真实图片后，取消勾选「封面是通用图库图片」**。
4. 「案例叙事」：只写有真实依据的章节，其余**留空**（前台自动隐藏）。
5. 点「保存」。想先不公开，把「在前台显示」取消勾选。

### 项目字段说明

| 字段（数据库 / 导出 JSON 中的名字） | 含义 | 为空时 |
| --- | --- | --- |
| `id` | 网址标识，决定链接 `/projects/<id>`，创建后不可改 | 自动生成 |
| `title` | 项目名称 | 必填 |
| `categoryId` | 所属分类 | 只在「全部」里显示 |
| `summary` | 一句话简介（卡片与分享预览） | 不显示 |
| `description` | 项目概述（Markdown） | 不显示 |
| `status` | `online` 已上线 / `completed` 已完成 / `developing` 开发中 / `testing` 测试中 / `poc` 概念验证 | — |
| `kinds` | 真实性类型：`work` 真实经历 / `solo` 个人独立项目 / `participated` 参与项目 / `ai` AI 辅助开发 / `poc` 概念验证（可多选） | 不显示标签 |
| `cover` / `coverIsStock` | 封面图 / 是否为通用图库图（为 true 时前台标注「示意配图」） | 显示渐变占位 |
| `gallery` | 截图列表（图片、说明、是否示意图） | 整个「截图与演示」章节隐藏 |
| `qrcode` / `demoVideo` | 二维码 / 演示视频（mp4、webm 直链直接播放） | 不显示 |
| `role` | 我的角色 | 不显示 |
| `periodStart` / `periodEnd` | 起止时间，如 `2025.07`、`至今` | 不显示 |
| `tools` | 使用工具标签 | 「使用工具」章节隐藏 |
| `content.*` | `background` 背景、`goals` 目标、`responsibilities` 承担的工作、`problems` 解决的问题、`process` 实施过程、`steps` 流程图步骤、`techSolution` 技术方案、`deliverables` 交付成果、`summary` 总结 | 对应章节隐藏 |
| `achievements` | 成果指标（名称 / 数值 / 备注） | **数值为空的指标不显示** |
| `links` | 相关链接按钮 | 不显示 |
| `featured` / `visible` | 首页精选 / 前台显示 | — |
| `createdAt` / `updatedAt` | 创建 / 更新时间（自动维护） | — |

### 文本格式（Markdown 子集）

正文框支持：`- 列表`、`1. 有序列表`、`**粗体**`、`` `代码` ``、`[文字](https://链接)`、`## 小标题`、`> 引用`。编辑框下方有「预览」按钮。**不支持 HTML**（出于安全）。

### 图片

- **上传**：在图片字段点「上传图片」，浏览器会先压缩（最长边 1600px，优先 WebP），再存入数据库，单张上限 3MB。支持 JPG / PNG / WebP / GIF，**不支持 SVG**（安全原因）。
- **选择已有**：从媒体库或内置图库里挑选。
- **外部地址**：直接填 `https://…` 图片链接。
- **静态文件**：把图片放进 `public/assets/`，填 `/assets/文件名.jpg`。想让它出现在选择器里，在 `src/data/assets.ts` 加一行。
- 替换图片：在字段里重新上传 / 选择即可，所有图片都经过统一的 `Media` 组件，自带懒加载、占位和失败兜底。

## 三、关于数据文件 `src/data/*.ts`

| 文件 | 内容 |
| --- | --- |
| `profile.ts` | 个人信息（含联系方式、证书、个人优势） |
| `site.ts` | 站点设置默认值 |
| `categories.ts` | 分类 |
| `projects.ts` | 项目 |
| `experience.ts` | 工作经历与教育经历 |
| `skills.ts` | 技能 |
| `logs.ts` | 成长日志 |
| `assets.ts` | 内置素材清单 |

它们只在两种情况下起作用：

1. **首次初始化**：数据库为空时，一次性写入数据库。
2. **兜底**：数据库连不上时，前台直接展示这些数据（只读），保证站点不白屏。

**初始化之后，内容以数据库为准**，直接改这些文件不会影响线上内容。日常请用后台。

如果你更喜欢「改文件」的方式：先修改这些文件，然后按下面的「重置」清空数据库，让它重新初始化。

### 重置为初始内容（会丢失后台所有修改！）

先在后台「概览」导出一份备份，然后在数据库里执行：

```sql
truncate projects, categories, experiences, skill_groups, logs, media;
delete from settings;
```

再访问一次站点（或 `/api/health`），会自动重新写入 `src/data` 里的内容。

## 四、真实性与内容规范（请遵守，这是这个站的核心）

1. **只写做过的、有依据的事**。没有数据支撑的指标，把「数值」留空，前台自动隐藏。
2. **类型标清楚**：真实经历 / 个人独立项目 / 参与项目 / AI 辅助开发 / 概念验证，不要混用。例如用 AI 工具辅助开发的个人项目，勾选「个人独立项目」+「AI 辅助开发」。
3. **图库图片不冒充现场图**：没有真实截图时可以用图库图做封面，但必须保持勾选「示意配图」，前台会自动标注。有真实素材后尽快替换（概览页会提醒）。
4. **涉及客户 / 公司敏感信息的内容不要放**（广告后台截图、客户名、未公开数据等）。可以用流程图和文字描述方法与职责代替。
5. **技能熟练度**只有「了解 / 熟悉 / 熟练」，没把握就选「不标注」。
6. 手机号等联系方式勾选「点击后才显示」。

## 五、简历页与 PDF

- `/resume` 由站点数据自动生成，和网站内容始终一致，不需要维护两份。
- 在页面点「打印 / 保存为 PDF」，目标选「另存为 PDF」。**打印前先点「点击查看」显示手机号**，否则 PDF 里是打码的号码。
- 想额外提供现成的 PDF 文件：把 PDF 放到 `public/assets/resume.pdf`，在「个人信息」的「PDF 简历链接」填 `/assets/resume.pdf`，首页和关于页会多出「下载 PDF」按钮。
- 简历页「项目经历」只列出标记为「个人独立项目」或「AI 辅助开发」的项目；工作类项目已包含在工作经历里。
